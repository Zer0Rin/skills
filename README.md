# Zer0Rin Skills

A public collection of reusable Codex skills, organized by domain.

## Character

- **character-four-view-builder** — Creates identity-consistent character sheets with a face close-up plus front, strict-side, and true-back full-body views.
- **character-four-view-builder-v2** — Adds Soft 3D game-CG and GPT Image 2-assisted modes, with restrained-detail and soft-lighting controls.

## Video

- **minimax-h3-prompt-expander** — Expands text, image, first/last-frame, and multi-reference ideas into executable MiniMax H3 video prompts.

## Install a Skill in Codex

Copy the selected skill directory into your Codex skills directory:

```bash
cp -R skills/character/character-four-view-builder ~/.codex/skills/
```

Restart Codex after installation so it discovers the new skill.
